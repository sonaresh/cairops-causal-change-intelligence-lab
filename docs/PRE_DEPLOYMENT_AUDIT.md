# CAIROps Pre-Deployment Audit

Audit date: 2026-08-12

This revision corrects deployment blockers and research-validity gaps found before AWS apply.

## Deployment corrections

- Corrected Terraform HCL formatting in `variables.tf` and `storage.tf`.
- Corrected Step Functions Lambda integration to use JSONPath `Parameters`/`OutputPath`.
- Protected the HTTP ingestion route with `AWS_IAM` authorization.
- Added the missing outcome-verifier output and node-security-group output.
- Fixed DynamoDB serialization of nested Python floats in the change normalizer.
- Added deterministic wait/validation behavior for metrics-server, CloudWatch Observability, application rollouts, and the LoadBalancer.
- Added immutable build tags rather than relying on `latest`.
- Added evidence archiving before Terraform destroy.

## Research corrections

- CAIROps now reads learned causal-edge confidence overrides from the DynamoDB graph table.
- Outcome verification updates controlled-experiment edge evidence in the graph table.
- Experiment runner invokes the outcome verifier and persists verifier output with each run.
- E4 now sends workload traffic through the dedicated EC2 dependency endpoint before the security-group rule is revoked/restored.
- E5 now measures the dedicated IAM probe Lambda instead of unrelated frontend traffic.
- E6 now uses an actual PostgreSQL query path with controlled query delay.
- E8 now changes traffic weighting toward a deliberately slow backend.
- E9 now creates an API-version compatibility mismatch rather than only setting a generic failure probability.
- E2/E3/E7 use controlled concurrent load so capacity/HPA/resource-limit changes are observable.
- The non-causal ML baseline uses leave-one-scenario-out predictions instead of reporting in-sample training accuracy.
- Causal localization output is now generated by the analysis code.

## Validation that must still happen in the user's AWS/Windows environment

The build environment does not contain Terraform, kubectl, Helm, Docker, or AWS credentials. Therefore the following must be rerun locally before apply:

1. `terraform fmt -recursive`
2. `terraform init -upgrade`
3. `terraform validate`
4. `terraform plan -out tfplan`
5. Review the new plan. Do not reuse an older saved plan after replacing files.
6. Only after plan review: `terraform apply "tfplan"`
